# Class 1 – Introduction to Cloud & Cloud Security
## 1. Introduction to Cloud Computing

Cloud Computing ka matlab hai internet ke through computing resources use karna, jaise storage, servers, databases, networking aur software.

Simple words mein:
Agar hum apne computer mein software ya data rakhne ke bajaye internet par available server ko use karein, to isay Cloud Computing kehte hain.

## Example:
Google Drive par files save karna cloud computing ki example hai. File hamare computer ke bajaye internet par cloud servers mein store hoti hai.

## Cloud Computing ke Benefits
Data ko kahin se bhi access kar sakte hain.
Internet ke through resources use kar sakte hain.
Cost kam ho sakti hai.
Resources ko zarurat ke mutabiq increase/decrease kar sakte hain.
Backup aur data storage easy hoti hai.
Organizations ko apna physical infrastructure kam rakhna padta hai.
## 2. Cloud Security

Cloud Security se murad cloud environment mein data, applications, servers aur other resources ko unauthorized access, attacks aur data loss se protect karna hai.

## Simple words mein:

Cloud + Security = Cloud mein stored data aur services ki protection.

Cloud Security ka Example

Agar kisi company ka customer data cloud server par stored hai, to company ko ensure karna hota hai ke:

Unauthorized person data access na kar sake.
Data chori na ho.
Data modify ya delete na ho.
Passwords aur accounts secure hon.
Data ka backup available ho.
Cloud Security ke Important Methods
Authentication: User ki identity verify karna.
Authorization: Decide karna ke user ko kis resource ki permission hai.
Encryption: Data ko secure/ unreadable form mein convert karna.
Access Control: Sirf authorized users ko access dena.
Backup: Data ki extra copy maintain karna.
Monitoring: Cloud activities ko continuously monitor karna.
## 3. Cloud Service Models

## Cloud services ko generally 3 major models mein divide kiya jata hai:

### IaaS – Infrastructure as a Service
### PaaS – Platform as a Service
### SaaS – Software as a Service
### 3.1 IaaS – Infrastructure as a Service

## IaaS mein cloud provider humein basic computing infrastructure provide karta hai, jaise:

Virtual Machines
Servers
Storage
Networking
Processing resources

User apne operating system aur applications ko manage kar sakta hai.

## Example

Agar company ko apna physical server khareedne ke bajaye cloud se virtual server mil jaye, to ye IaaS hai.

## Simple Example:
IaaS ko aise samjhein jaise aapko ek empty house diya gaya ho. Building available hai, lekin andar ka setup aap apni requirement ke mutabiq karte hain.

## IaaS mein:

Cloud Provider: Physical hardware, networking aur virtualization manage karta hai.

User: Operating system, applications aur apna data manage karta hai.

3.2 PaaS – Platform as a Service

PaaS mein cloud provider developers ko ek ready-made platform provide karta hai jahan woh applications develop, test aur deploy kar sakte hain.

User ko server aur operating system ki complete management nahi karni padti.

## Example

Aik developer ko application banani hai. Usay physical server setup karne ki zarurat nahi. Woh cloud platform use karke directly application develop aur deploy kar sakta hai.

## Simple Example

PaaS ko ready-made kitchen ki tarah samjhein.

Kitchen ka basic setup already available hai. Aapka focus sirf food/cooking yani application development par hota hai.

PaaS ka Main Purpose
Application development
Application testing
Application deployment
Developers ka time save karna
3.3 SaaS – Software as a Service

SaaS mein complete software/application internet ke through provide ki jati hai.

User ko software install ya underlying server manage karne ki zarurat nahi hoti.

## Examples
Gmail
Google Docs
Microsoft 365
Online CRM software
Simple Example

Aap browser open karte hain aur Gmail use karte hain. Aapko Gmail ka server, operating system ya infrastructure manage nahi karna padta.

Ye SaaS hai.

## 4. IaaS vs PaaS vs SaaS
Model	Full Form	Main Idea
IaaS	Infrastructure as a Service	Virtual servers, storage, networking
PaaS	Platform as a Service	Application development platform
SaaS	Software as a Service	Ready-to-use software
Easy Trick

IaaS → Infrastructure

PaaS → Platform

SaaS → Software

## 5. Cloud Economics

Cloud Economics ka matlab hai cloud computing ki cost aur financial benefits ko samajhna.

Cloud use karne se organization ko ye decide karna hota hai ke cloud resources par kitna kharcha hoga aur traditional infrastructure ke comparison mein cost kaise change hogi.

Cloud Economics ke important concepts:

CAPEX
OPEX
TCO
## 6. CAPEX – Capital Expenditure

CAPEX ka matlab hai Capital Expenditure.

Is mein organization long-term physical assets purchase karne par paisa spend karti hai.

## Example

## Agar company:

Physical servers khareedti hai
Networking equipment khareedti hai
Data center banati hai
Storage hardware purchase karti hai

to ye CAPEX ho sakta hai.

## Simple Urdu

CAPEX = Shuru mein bari investment karke physical equipment khareedna.

## 7. OPEX – Operational Expenditure

OPEX ka matlab hai Operational Expenditure.

Ye daily ya ongoing operational expenses hote hain.

Cloud computing mein organization aksar resources ko use karne ke according payment karti hai.

## Example

Company cloud server ko monthly basis par use karti hai aur monthly bill pay karti hai.

Simple Urdu

OPEX = Daily/ongoing expenses jo service ko operate karne ke liye pay kiye jate hain.

## 8. TCO – Total Cost of Ownership

TCO ka matlab hai Total Cost of Ownership.

Iska matlab kisi technology ya system ki overall cost ko calculate karna hai.

Sirf purchase price nahi, balki related expenses bhi consider kiye jate hain.

## TCO mein include ho sakta hai:
Hardware cost
Software cost
Maintenance
Electricity
Cooling
Staff/administration
Upgrades
Repairs
Simple Urdu

TCO = Kisi system ko purchase aur operate karne ki total overall cost.

## 9. Benefits of Cloud Computing

## Cloud Computing ke important benefits:

## 1. Cost Saving

Physical hardware purchase karne ki zarurat kam ho sakti hai.

## 2. Scalability

Resources ko requirement ke mutabiq increase ya decrease kar sakte hain.

## 3. Accessibility

Internet ke through data aur applications access ki ja sakti hain.

## 4. Flexibility

Resources ko quickly change aur configure kiya ja sakta hai.

## 5. Backup

Cloud environment mein data backup solutions available ho sakte hain.

## 6. High Availability

Cloud providers multiple systems aur locations use kar sakte hain taake services available rahen.

## 7. Faster Deployment

New resources aur applications relatively quickly deploy ki ja sakti hain.

## 10. Data Centers – Basic Concept

Data Center aik physical facility hoti hai jahan large number mein servers, storage systems, networking equipment aur other IT infrastructure rakha jata hai.

Cloud computing ke peeche data centers important role play karte hain.

Data Center mein kya hota hai?
Servers
Storage systems
Network devices
Routers
Switches
Cooling systems
Power systems
Security systems
Simple Example

Aap jab cloud par koi file upload karte hain, to woh file kisi cloud provider ke data center ke servers par store ho sakti hai.

Data Center ki Importance

## Data centers:

Data ko store karte hain.
Applications ko run karte hain.
Cloud services provide karte hain.
Networking aur computing resources provide karte hain.
Security aur physical protection provide karte hain.
