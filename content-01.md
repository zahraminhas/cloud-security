1. Introduction to Cloud & Cloud Security
Cloud kya hota hai?

Cloud ka mtlb hota hai ke hum Internet ke through computing resources use krty hain, jasy storage, servers, databases aur software.

Example:
Google Drive pr hum apni files online save krty hain. Humein apne computer ki hard drive mein hi sab kuch rakhna zaroori nahi hota.

Cloud Security kya hoti hai?

Cloud Security ka mtlb hai cloud mein mojood data, applications aur systems ko secure rakhna.

Is mein unauthorized person ko data access krny se rokna, cyber attacks se protection aur data loss se bachao shamil hota hai.

Example:
Cloud account par strong password aur MFA lagana security ka part hai.

2. Cloud Service Models

Cloud ke 3 main service models hoty hain:

IaaS – Infrastructure as a Service

IaaS mein cloud provider humein infrastructure provide krta hai, jasy:

Virtual machines
Servers
Storage
Networking

Easy example:
Aik company physical server khareedny ke bajaye cloud provider se virtual server rent kar leti hai.

Yaad rakho:
IaaS = Infrastructure

PaaS – Platform as a Service

PaaS mein cloud provider aik platform deta hai jahan developers applications bana, test aur deploy krty hain.

Easy example:
Developer ko application banani hai, lekin usay physical server manage nahi krna. Woh PaaS platform use kr ke application bana sakta hai.

Yaad rakho:
PaaS = Platform

SaaS – Software as a Service

SaaS mein humein ready-made software Internet ke through milta hai.

Examples:

Gmail
Google Docs
Microsoft 365

Humein software ke servers ya infrastructure khud manage nahi krny party.

Yaad rakho:
SaaS = Software

⭐ Easy Formula

IaaS → Infrastructure
PaaS → Platform
SaaS → Software

3. Cloud Economics

Cloud Economics ka mtlb hai cloud ko use krny ki cost aur financial benefits ko samajhna.

Is ke important concepts:

CAPEX – Capital Expenditure

CAPEX ka mtlb hai physical equipment khareedny par paisa lagana.

Example:
Company ne apna physical server, storage aur networking equipment khareeda.

➡️ Ye CAPEX hai.

Easy: CAPEX = Buy

OPEX – Operational Expenditure

OPEX ka mtlb hai services ko operate/use krny ka ongoing kharcha.

Example:
Company cloud provider ko har month cloud services ka bill pay krti hai.

➡️ Ye OPEX hai.

Easy: OPEX = Ongoing expense

TCO – Total Cost of Ownership

TCO ka mtlb hai kisi system ko own aur operate krny ki total cost.

Is mein different costs aa sakti hain:

Hardware
Software
Maintenance
Electricity
Staff
Infrastructure

Easy:
TCO = Total cost

4. Benefits of Cloud Computing
1. Cost Saving

Cloud use krny se physical hardware khareedny aur maintain krny ka kharcha kam ho sakta hai.

2. Scalability

Requirement ke according resources increase ya decrease kr sakty hain.

Example: Agar website par users zyada aa jayein to resources increase kiye ja sakty hain.

3. Flexibility

Cloud services ko Internet ke through different locations aur devices se access kiya ja sakta hai.

4. Availability

Data aur applications ko zaroorat ke waqt access kiya ja sakta hai, service design par depend karta hai.

5. Backup & Recovery

Cloud services data ka backup aur recovery karne mein help kar sakti hain.

6. Fast Deployment

Cloud mein new resources aur services relatively quickly setup ki ja sakti hain.

5. Data Center ka Concept

Data Center aik physical facility hoti hai jahan bohat se:

Servers
Storage systems
Network devices
Power systems
Cooling systems
Security systems

mojood hoty hain.

Easy example:
Jab hum cloud service use krty hain, to cloud asal mein hawa mein nahi hota 😄. Us ke peeche physical servers data centers mein mojood hoty hain.
